Video Sorter







  
1
Scan

    
Lists both shares, hashes new files and looks them up on StashDB. Read-only; only new or changed files are hashed.

    


  
2
Plan

    
Decides for every video in xtosort$ the site folder and the new name, and finds duplicates. Read-only.

    


  
3
Review

    
Tick skip on anything that should stay where it is; skipped rows are not touched. Sample clips of movie rips are deleted by default; tick skip to keep one.

    

      

    
SkipActionFileConf.Notes

    


  
4
Validate & execute

    
Validation checks every operation on the file server (source, size, destination, folders) and changes nothing. Executing does a same-volume move, so it is instant and never overwrites.

    






  
Duplicates

    
Files in xtosort$\_dupes that were sorted out because a better or identical copy exists. Certain means the kept copy was proven identical (byte compare on the server) or the same scene at equal or better quality (same StashDB scene, same duration, matching frames).

Automatic nightly run

    
Scans, plans and runs everything it is confident about, and leaves the rest in xtosort$ for you to review on the Sort tab. It only deletes what you switch on below.

Always: a file whose content fingerprint matches a StashDB scene goes to its studio folder with the standard name.

    

    
Safety limitfiles per night. If a run would handle more than that, it does nothing and tells you.
